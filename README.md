# Мой день

Личный дневник дня. Одна статическая страница, пишет ответы в Google Drive
владельца областью `drive.file` - то есть видит только те файлы, которые создала
сама.

Список вопросов в открытом виде здесь намеренно отсутствует. С 19.10.2026 он
лежит файлом `questions.enc`, зашифрованным AES-256-GCM; ключ приезжает один раз
короткой ссылкой `…/moy-den/#k=<ключ>` и живёт в localStorage браузера. Страница
перечитывает файл при каждом открытии, так что новая версия опросника доезжает
сама. Репозиторий публичный: без ключа файл — шум.

Файл пишет `personal-agent/tools/publish_diary_questions.py --push`.
Старый путь — весь список во фрагменте ссылки (`#q=…`) — тоже работает.
