# Мой день

Личный дневник дня. Одна статическая страница, пишет ответы в Google Drive
владельца областью `drive.file` - то есть видит только те файлы, которые создала
сама.

Список вопросов здесь намеренно отсутствует: он приезжает ссылкой во фрагменте
адреса и живёт в localStorage браузера. Репозиторий публичный, и личному тут не
место.
